# Repact — AI fitness challenges

Активная веб-версия Repact. Собрана
напрямую со Swift-исходников, а не из старой версии в
`../Archive/MyChallengeWeb`. Чистый
HTML/CSS/JS — ничего собирать не надо.

## Что портировано (весь функционал iOS-аппа)

- **Онбординг** (8 шагов): пол, возраст, рост, вес, уровень, максимум за подход
  → расчёт дневной нормы + сводка.
- **4 вкладки**: Твои челленджи · Челленджи (список + создание) · Статистика · Профиль.
- **Детали челленджа**: банк, «сегодня», правила, соцдоказательство, до/после,
  таблица лидеров дня.
- **Создание**: упражнение (отжимания/приседания/комбо), норма, срок, пропуски,
  прогрессия, взнос.
- **Вступление**: вес, максимум, фото «до».
- **Сессия с камерой**: скелет, счётчик повторов, голос, запись ролика.
- **Поздравления**: день закрыт / челлендж завершён + шеринг-карточка.
- **Статистика**: недельный объём (график), активность по дням, журнал.
- **Профиль**: данные тела, замеры, фото до/после под замком, кошелёк.
- **RU / EN** (переключатель в шапке), валюта $ / локальная.

Дизайн-система — порт `Theme.swift` (`styles.css`): чёрный фон, огненный
оранжевый акцент, изумрудный «деньги», SF Pro / monospace.

## Подсчёт повторов

`pose.js` — точный порт `RepCounter.swift` на MediaPipe Pose в браузере:
угол сгиба локтей/коленей, среднее видимых сторон, гистерезис 110°/140°,
grace-кадры и анти-чит по ходу корпуса и неподвижности ладоней/стоп.

## Живая версия (для друзей)

**https://pysarenkovv.github.io/fitstake/** — постоянная HTTPS-ссылка, кидай друзьям.

Репозиторий: **github.com/PysarenkoVV/fitstake** (public, GitHub Pages с ветки
`main`). Обновление = `git commit` + `git push origin main` (Pages пересобирается
сам за ~минуту; при правках оболочки поднимать `CACHE` в `sw.js`).

Браузер даёт камеру только на `https://` или `localhost` — поэтому и нужен
хостинг (по локалке `http://192.168.x.x` камера не заработает).

## На домашний экран iPhone (PWA)

Открой ссылку (https!) в Safari → Поделиться → «На экран „Домой“».
Иконка Repact, полноэкранный режим, офлайн-кэш оболочки (`sw.js`; при правках
подними `CACHE`). Модель MediaPipe тянется с CDN при первом запуске сессии.

## Текущее ограничение

Аккаунты, публичные челленджи и общий прогресс синхронизируются через Firebase.
Локальные челленджи, тестовый баланс, фото и часть профиля остаются на устройстве.
Коины тестовые — реальные деньги не участвуют.

## Файлы

- `index.html` — оболочка + PWA-мета
- `styles.css` — дизайн-система (порт `Theme.swift`)
- `app.js` — состояние, модели, экраны, i18n, шеринг
- `pose.js` — камера, MediaPipe, `RepCounter`, запись
- `manifest.json`, `sw.js`, `icons/` — PWA
