# 🤖 AI Team — локальная система управления разработкой

Локальная система, которая превращает OpenAI в менеджера/архитектора, а Claude Code в разработчика.

## Как это работает

```
Вы
  ↓ (описание задачи)
npm run ai-team
  ↓
Собирает контекст проекта
  ↓
OpenAI анализирует и создаёт план
  ↓
Вы подтверждаете
  ↓
Git checkpoint (точка возврата)
  ↓
Claude Code разрабатывает
  ↓
OpenAI проверяет результат
  ↓
Нужны правки? → Claude исправляет → снова проверка
  (не более 2 раундов исправлений)
  ↓
Финальный отчёт
```

OpenAI используется через актуальный **Responses API** (`client.responses.create`).

## Требования

- **Node.js 18+** — для запуска скрипта
- **OpenAI API ключ** — от https://platform.openai.com/account/api-keys
- **Claude Code** — `npm install -g @anthropic-ai/claude-code` (нужен, чтобы система сама вносила правки)
- **Git** (опционально) — для создания checkpoint-ов и отката

## Первичная настройка

### 1. Установите зависимости

```bash
npm install
```

### 2. Создайте .env файл

```bash
cp .env.example .env
```

### 3. Добавьте ваш OpenAI API ключ

Отредактируйте `.env`:

```env
OPENAI_API_KEY=sk-... # ваш реальный ключ из platform.openai.com
OPENAI_MODEL=gpt-4o    # или gpt-4-turbo, gpt-3.5-turbo
```

### 4. (Опционально) Установите Claude Code

Если хотите, чтобы система запускала Claude автоматически:

```bash
npm install -g @anthropic-ai/claude-code
claude  # первый запуск попросит войти в аккаунт
```

## Использование

### Запустить AI Team

```bash
npm run ai-team
```

### Что будет происходить

1. **Система запросит описание задачи**
   - Напишите на русском или английском
   - Например: "Добавить кнопку скачивания результатов"

2. **OpenAI проанализирует**
   - Поймёт, что нужно сделать
   - Изучит архитектуру проекта
   - Создаст UX/UI анализ
   - Подготовит пошаговый план
   - Напишет техническое задание для разработчика

3. **Вы подтвердите план**
   - Увидите полный анализ
   - Скажете "да" или "нет"

4. **Если согласились**
   - Система создаст git checkpoint (точка возврата)
   - Запустит Claude Code с техническим заданием
   - Claude будет менять файлы проекта

5. **Claude вносит изменения**
   - Работает в неинтерактивном режиме (`claude -p`)
   - Правки файлов разрешены (`acceptEdits`), но **без** опасного `dangerously-skip-permissions`
   - Работа ограничена только этой папкой

6. **Проверка и исправления**
   - Система получит `git diff` — список всех изменений
   - OpenAI проверит результат (задача, UX/UI, ошибки, безопасность, лишний код)
   - Если найдены проблемы — Claude их исправит, затем повторная проверка
   - Не более **2 раундов исправлений**, чтобы не работать бесконечно

7. **Финальный отчёт**
   - Что сделано, какие файлы изменены, что проверить вручную, как откатить

## Результаты

Все отчёты сохраняются в папке `.ai-team/reports`:

- `*_analysis.md` — анализ задачи и техзадание от OpenAI
- `*_verification-1.md`, `*_verification-2.md`, … — проверки результата по раундам
- `*_final-report.md` — итоговый отчёт

## Откат (если что-то пошло не так)

Если Git был доступен, откатитесь на главную ветку:

```bash
git checkout -         # вернуться на главную ветку
git branch -D ai-team-* # удалить ветку с изменениями
```

Или отредактируйте файлы вручную, следуя инструкциям в отчёте.

## Безопасность

✓ **OPENAI_API_KEY** никогда не попадёт в git (в `.gitignore`)  
✓ **Секретные данные** автоматически исключаются из контекста  
✓ **node_modules** не отправляются в OpenAI  
✓ **Git checkpoint** перед любыми изменениями  
✓ **Claude запускается без** `dangerously-skip-permissions` и ограничен этой папкой  
✓ **Цикл исправлений ограничен** 2 раундами — система не работает бесконечно  
✓ **Никаких опасных операций** без вашего подтверждения

## Трубулшутинг

### Ошибка: "OPENAI_API_KEY не найден"

**Решение:**
```bash
cp .env.example .env
# отредактируйте .env и добавьте реальный ключ
```

### Ошибка: "Claude Code не установлен"

**Решение:**
```bash
npm install -g @anthropic-ai/claude-code
claude            # первый запуск попросит войти в аккаунт
npm run ai-team   # запустите снова
```

### OpenAI отвечает с ошибкой 401

**Решение:**
- Проверьте, что OPENAI_API_KEY в .env правильный
- Ключ должен начинаться с `sk-`
- Проверьте на https://platform.openai.com/account/api-keys, что ключ активен

### OpenAI отвечает с ошибкой 429 (Rate limit)

**Решение:**
- Подождите несколько минут
- Проверьте лимиты вашего аккаунта на https://platform.openai.com/account/billing/limits

## Какие модели OpenAI поддерживаются

Любые доступные в вашем аккаунте:
- `gpt-4o` — новая, мощная и быстрая
- `gpt-4-turbo` — хороший баланс цены и качества
- `gpt-4` — медленнее, дороже
- `gpt-3.5-turbo` — дешёвый, но менее умный

Установите желаемую модель в `.env` переменной `OPENAI_MODEL`.

## FAQ

**Q: Система отправляет весь проект в OpenAI?**
A: Нет, только необходимый контекст — структура, package.json, README, основные файлы.

**Q: Мой API ключ защищён?**
A: Да, ключ хранится локально в `.env`, который в `.gitignore`. В OpenAI отправляется только описание задачи и контекст проекта.

**Q: Можно ли использовать без Claude Code?**
A: Да! Без Claude система покажет план и техническое задание, которое вы сможете выполнить вручную.

**Q: Можно ли отменить изменения?**
A: Да! Используйте `git checkout -` или откатитесь на точку возврата, которая была создана до запуска Claude.

**Q: Сколько это стоит?**
A: Зависит от объёма контекста и модели. Обычно очень дёшево — ~0.01-0.10 USD за анализ задачи.
